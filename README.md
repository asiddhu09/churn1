# Customer Churn Analysis
Churn Analysis for App Subscription Users	2025
Tools: SQL, Python, Power BI, Excel
•	Studied subscription and usage data from a simulated app-based service to understand why users cancel or downgrade.
•	Wrote SQL queries joining user profile, subscription, and in-app activity tables to calculate session frequency, feature usage, and days since last login.
•	Conducted cohort analysis in Python to track monthly retention across signup cohorts, revealing a sharp drop-off right after the free-trial period ended.
•	Segmented users into 'active', 'at-risk', and 'churned' groups based on engagement thresholds and compared behaviour patterns across segments.
•	Built Power BI visualizations of retention curves and churn by plan and recommended targeted re-engagement emails for 'at-risk' users before trial expiry.
